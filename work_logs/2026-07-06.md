## 补全 CP2K 和 Quantum ESPRESSO 两条路径

在补充 “其余软件中的 LOBSTER 使用方式” 时，没有停留在纯文档说明，而是继续把两条路径做成可执行的 skill 命令。

新增命令：

- `prepare_input_cp2k`
- `prepare_input_qe`
- `write_file_manifest`

设计上采用了“显式 file manifest staging”策略，而不是在脚本里硬编码 CP2K/QE 的接口文件名。原因是：

- 当前仓库中没有现成的 `cp2k` 或 `qe` skill 作为约束来源
- 本地依赖与 `pymatgen` 现状并未提供明确、稳定的 CP2K/QE LOBSTER staging 接口
- 不同环境下 CP2K 和 QE 的导出文件名、目录结构可能不同

因此当前实现方式是：

1. 用户先准备好 CP2K 或 QE 侧实际产出的 LOBSTER 所需文件
2. 用 `write_file_manifest --code cp2k|qe` 生成模板
3. 按本机真实文件名修改 manifest
4. 调用：
   - `prepare_input_cp2k`
   - `prepare_input_qe`

这些命令会：

- 从 `--source_dir` 按 manifest 显式收集文件
- 根据 `species` + `basis-functions` 生成 `lobsterin`
- 组装成独立的 LOBSTER 计算目录

对应新增参考文件：

- `agents/Agent/skills/lobster/references/cp2k.md`
- `agents/Agent/skills/lobster/references/quantum-espresso.md`
