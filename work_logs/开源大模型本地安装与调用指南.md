# 开源大模型本地安装与调用指南

本文介绍如何在 Ubuntu/Linux 计算机或 GPU 服务器上运行 DeepSeek 等开源大语言模型，并通过命令行、Python 或 HTTP API 调用。

主要包括：

- Ollama：最简单的本地模型运行方式
- Hugging Face Transformers：直接加载和控制模型
- vLLM：将模型部署成高性能 API 服务
- GPU 选择与局域网访问
- 常用检查和故障排除命令

---

## 1. 基本概念

| 名称 | 主要作用 |
|---|---|
| DeepSeek、Qwen、Llama | 大语言模型本身 |
| Hugging Face Hub | 查找、下载和分享模型的平台 |
| Transformers | 使用 Python 加载和运行 Hugging Face 模型的库 |
| Ollama | 快速下载并在本地运行量化模型 |
| vLLM | 将模型部署成高性能、OpenAI 兼容的 API 服务 |
| Open WebUI | 为本地模型提供类似 ChatGPT 的网页界面 |

常见工作流程：

```text
Hugging Face 上的模型
        ↓
Ollama / Transformers / vLLM
        ↓
本地 GPU 推理
        ↓
终端 / Python / Agent / 网页调用
```

# 2. 方法一：使用 Ollama

Ollama 最适合初次尝试本地大模型。它会自动管理模型下载、量化权重、GPU 加载和本地 API。

## 2.1 检查 GPU

```bash
nvidia-smi
```

检查 CUDA 是否可以被 PyTorch 使用：

```bash
python - <<'PY'
import torch

print("PyTorch version:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())
print("CUDA version:", torch.version.cuda)

if torch.cuda.is_available():
    print("GPU count:", torch.cuda.device_count())
    for i in range(torch.cuda.device_count()):
        print(i, torch.cuda.get_device_name(i))
PY
```

---

## 2.2 安装 Ollama

Ubuntu/Linux：

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

确认安装：

```bash
ollama --version
```

检查服务状态：

```bash
systemctl status ollama
```

启动服务：

```bash
sudo systemctl start ollama
```

设置开机自动启动：

```bash
sudo systemctl enable ollama
```

重启服务：

```bash
sudo systemctl restart ollama
```

查看日志：

```bash
journalctl -e -u ollama
```

如果系统没有使用 systemd，也可以直接运行：

```bash
ollama serve
```

Ollama 默认 API 地址：

```text
http://127.0.0.1:11434
```

## 2.6 使用 Python 调用 Ollama

创建虚拟环境：

```bash
python -m venv ~/venvs/ollama-python
```

激活环境：

```bash
source ~/venvs/ollama-python/bin/activate
```

升级 pip：

```bash
python -m pip install --upgrade pip
```

安装 Ollama Python 客户端：

```bash
pip install ollama
```

创建 `ollama_test.py`：

```python
from ollama import chat

response = chat(
    model="deepseek-r1:7b",
    messages=[
        {
            "role": "system",
            "content": "你是一名计算材料学和Python编程助手。",
        },
        {
            "role": "user",
            "content": "请解释MACE与DeepMD的主要区别。",
        },
    ],
)

print(response.message.content)
```

运行：

```bash
python ollama_test.py
```

也可以使用 `requests`：

```bash
pip install requests
```

```python
import requests

url = "http://127.0.0.1:11434/api/chat"

payload = {
    "model": "deepseek-r1:7b",
    "messages": [
        {
            "role": "user",
            "content": "请解释ZnO表面吸附能的计算方法。",
        }
    ],
    "stream": False,
}

response = requests.post(url, json=payload, timeout=600)
response.raise_for_status()

result = response.json()
print(result["message"]["content"])
```

## 2.7 指定 Ollama 使用哪些 GPU

临时限制只使用物理 GPU 0：

```bash
CUDA_VISIBLE_DEVICES=0 ollama serve
```

使用物理 GPU 0 和 2：

```bash
CUDA_VISIBLE_DEVICES=0,2 ollama serve
```

注意：如果 Ollama 已由 systemd 服务启动，需要先停止服务，否则手动启动时可能出现端口占用。

```bash
sudo systemctl stop ollama
```

然后运行：

```bash
CUDA_VISIBLE_DEVICES=0,2 ollama serve
```

检查 GPU 使用情况：

```bash
watch -n 1 nvidia-smi
```

退出 `watch`：

```text
Ctrl+C
```

## 2.8 修改 Ollama 模型保存位置

模型文件可能占用几十 GB。可以将模型保存到大容量磁盘。

例如保存到：

```text
/home/wu/ollama_models
```

创建目录：

```bash
mkdir -p /home/wu/ollama_models
```

临时指定：

```bash
OLLAMA_MODELS=/home/wu/ollama_models ollama serve
```

如果 Ollama 使用 systemd，可以创建覆盖配置：

```bash
sudo systemctl edit ollama
```

写入：

```ini
[Service]
Environment="OLLAMA_MODELS=/home/wu/ollama_models"
Environment="CUDA_VISIBLE_DEVICES=0,2"
```

保存后执行：

```bash
sudo systemctl daemon-reload
sudo systemctl restart ollama
```

验证：

```bash
systemctl show ollama --property=Environment
```

# 3. 方法二：使用 Hugging Face Transformers

这种方式适合：

- 直接加载原始模型权重
- 调整生成参数
- 读取 hidden states
- 进行 LoRA 微调
- 研究模型结构
- 将模型嵌入自定义 Python 程序

与 Ollama 相比，Transformers 更灵活，但环境配置和显存要求通常更高。

---

使用 venv：

```bash
python -m venv ~/venvs/transformers
source ~/venvs/transformers/bin/activate
python -m pip install --upgrade pip
```

或者使用 Conda：

```bash
conda create -n transformers python=3.11 -y
conda activate transformers
```

## 3.4 使用 pipeline 运行模型

创建 `hf_pipeline_test.py`：

```python
import torch
from transformers import pipeline

model_name = "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B"

generator = pipeline(
    task="text-generation",
    model=model_name,
    torch_dtype=torch.bfloat16,
    device_map="auto",
)

messages = [
    {
        "role": "user",
        "content": "请简单解释机器学习原子间势。",
    }
]

output = generator(
    messages,
    max_new_tokens=512,
    do_sample=True,
    temperature=0.6,
)

print(output[0]["generated_text"])
```

运行：

```bash
python hf_pipeline_test.py
```

## 3.5 使用 AutoModel 手动加载

创建 `hf_model_test.py`：

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B"

tokenizer = AutoTokenizer.from_pretrained(model_name)

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.bfloat16,
    device_map="auto",
)

messages = [
    {
        "role": "system",
        "content": "你是一名计算材料学助手。",
    },
    {
        "role": "user",
        "content": "请解释NEB计算的基本流程。",
    },
]

text = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
)

inputs = tokenizer(
    text,
    return_tensors="pt",
).to(model.device)

with torch.inference_mode():
    outputs = model.generate(
        **inputs,
        max_new_tokens=512,
        do_sample=True,
        temperature=0.6,
        top_p=0.95,
    )

new_tokens = outputs[0][inputs["input_ids"].shape[1]:]

answer = tokenizer.decode(
    new_tokens,
    skip_special_tokens=True,
)

print(answer)
```

运行：

```bash
python hf_model_test.py
```

# 4. 方法三：使用 vLLM 部署模型服务器

vLLM 适合：

- GPU 服务器
- 多用户访问
- 高并发推理
- 为 Agent 提供统一 API
- 使用 OpenAI 兼容接口
- 多 GPU 张量并行

---

## 4.1 创建环境

```bash
conda create -n vllm python=3.11 -y
conda activate vllm
```

安装 vLLM：

```bash
pip install vllm
```

确认命令：

```bash
vllm --help
```

检查 GPU：

```bash
nvidia-smi
```

---

## 4.2 使用单块 GPU 启动服务

```bash
CUDA_VISIBLE_DEVICES=0 \
vllm serve deepseek-ai/DeepSeek-R1-Distill-Qwen-7B \
  --host 0.0.0.0 \
  --port 8000 \
  --dtype auto
```

默认 API 地址：

```text
http://127.0.0.1:8000/v1
```

---

## 4.3 使用 GPU 0 和 2

```bash
CUDA_VISIBLE_DEVICES=0,2 \
vllm serve deepseek-ai/DeepSeek-R1-Distill-Qwen-7B \
  --host 0.0.0.0 \
  --port 8000 \
  --tensor-parallel-size 2 \
  --dtype auto
```

说明：

```text
CUDA_VISIBLE_DEVICES=0,2
```

表示只让程序看到物理 GPU 0 和 2。

```text
--tensor-parallel-size 2
```

表示模型使用两块可见 GPU 进行张量并行。

多 GPU 并行通常要求 GPU 型号、显存和互联条件合适。

---

## 4.4 设置 API Key

```bash
CUDA_VISIBLE_DEVICES=0,2 \
vllm serve deepseek-ai/DeepSeek-R1-Distill-Qwen-7B \
  --host 0.0.0.0 \
  --port 8000 \
  --tensor-parallel-size 2 \
  --dtype auto \
  --api-key local-secret-key
```



# 5. 模型大小选择

实际显存占用会受到以下因素影响：

- 参数规模
- 权重量化精度
- 上下文长度
- KV Cache
- 并发请求数量
- 推理框架
- 是否使用多 GPU
- 模型架构

大致参考：

| 模型规模 | 量化后大致内存或显存 | 推荐用途 |
|---|---:|---|
| 1.5B | 约 2～4 GB | 功能测试、简单问答 |
| 7B/8B | 约 5～10 GB | 日常问答、代码辅助 |
| 14B | 约 10～18 GB | 更复杂的推理与编程 |
| 32B | 约 20～40 GB | 较高质量研究辅助 |
| 70B | 约 45～90 GB | 多 GPU 服务器 |
| 671B | 数百 GB 以上 | 大型 GPU 集群 |

运行前检查显存：

```bash
nvidia-smi
```

持续监控：

```bash
watch -n 1 nvidia-smi
```

# 6. 常见问题

## 6.1 输入命令后一直没有输出

可能正在下载或加载模型。

检查网络：

```bash
ping -c 4 huggingface.co
```

检查硬盘空间：

```bash
df -h
```

检查模型目录：

```bash
du -sh ~/.ollama
```

检查 GPU：

```bash
nvidia-smi
```

查看 Ollama 日志：

```bash
journalctl -f -u ollama
```

---

## 6.2 端口已经被占用

检查 11434 端口：

```bash
sudo lsof -i :11434
```

检查 8000 端口：

```bash
sudo lsof -i :8000
```

也可以使用：

```bash
ss -ltnp | grep 11434
```

结束指定进程：

```bash
kill 进程号
```

必要时强制结束：

```bash
kill -9 进程号
```

---

## 6.3 CUDA out of memory

先检查显存：

```bash
nvidia-smi
```

结束不需要的 GPU 进程：

```bash
kill 进程号
```

可采用以下方法：

1. 换用更小的模型。
2. 使用量化模型。
3. 缩短上下文长度。
4. 降低并发数。
5. 使用多 GPU。
6. 使用 Ollama 运行较小的量化版本。

---

## 6.4 Ollama 没有使用 GPU

检查驱动：

```bash
nvidia-smi
```

检查 Ollama 日志：

```bash
journalctl -e -u ollama
```

运行模型时监控：

```bash
watch -n 1 nvidia-smi
```

重启服务：

```bash
sudo systemctl restart ollama
```

## 安全注意事项

- 不要把 Hugging Face Token 或 API Key 上传到 GitHub。
- 不要把没有认证的 Ollama 或 vLLM 端口直接暴露到公网。
- 在共享服务器上，先确认 GPU 是否被其他人使用。
- 模型权重可能占用几十到数百 GB，下载前检查磁盘空间。
- 部署模型前阅读模型许可证，确认是否允许目标用途。
