## 新增 Agent skill: ptomodel

新增文件：

```text
agents/Agent/skills/ptomodel/
  SKILL.md
  scripts/
    ptomodel_tools.py
```

用途：

```text
paperread outputs
-> ptomodel 筛选有用实验/表面信息
-> ptomodel 做等价与归一化映射
-> ptomodel 输出 Agent-ready JSON
-> surface-modeling 读取并执行可支持任务
```

当前 `ptomodel` 关注的信息包括：

- 面指数 / 晶面
- 负载纳米颗粒或团簇种类
- 单原子物种
- 材料类别
- 反应类型
- 吸附物 / 吸附位 / 覆盖度
- 缺陷 / 活性位
- 推荐建模任务与可执行任务

当前自动执行任务仍限制为：

- `vacancy_landscape`
- `adsorbate_landscape`
- `surface_cluster_builder`

其余任务保留在 `deferred_tasks` 中。
