- 新增 `tests/modeling/test_mlip_interfaces.py` 和 opt-in 的
  `tests/external/test_mlip_calculators.py`；同步冒烟、参数 schema 和团簇默认值回归测试。

不负责安装 MLIP。按此要求将原先仅命令行可用的 MLIP 接口接入统一 YAML 工作流。

- 新增 `modeling/surface/mlip_config.py`：读取 `genkai.yaml` 中的命名配置，统一 Python 环境、
  本地模型/UMA 名称、设备、精度、任务头和公共弛豫设置；支持独立环境及可选的激活脚本。
  相对路径以配置文件为准；保留 venv Python 的符号链接路径，不解析成系统解释器。

  `slab`、`vacancy`、`adsorbate` 可用 `mlip: <配置名>` 启用计算。旧任务默认保持结构生成行为。
  `check` 检查环境/模型路径而不加载模型；执行时自动选择该配置的 Python 和后端参数。
- 新增 `modeling/surface/setup.py`，改造 `install.sh`：自动发现/交互登记已安装后端，生成配置、
  11 个任务模板和 `./genkai`。`--mlip` 兼容参数不再安装后端，`--torch-index-url` 明确拒绝。
  主环境只安装 `.[test]`；每个后端在 `.genkai/runtimes/` 中获得独立项目依赖环境。
- 针对已有 venv，显式处理其 site-packages 和可编辑安装的 `.pth`，因为标准嵌套 venv 不自动继承
  另一个 venv 的安装。增加真实嵌套 venv 回归测试，并验证重复配置不丢失继承路径。
- 收集源环境依赖版本作为约束，只安装 Genkai 基础依赖，不安装 MLIP/torch，不修改源环境。

  契约新增 `empirical_potential`，以便离线 EMT 集成测试不冒充 MLIP 结果。
