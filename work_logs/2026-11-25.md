# 2026-11-25（SAGE 分支）：简化用法、常见体系配方、覆盖层遮挡修复

## 背景

用户认为流水线用法仍然复杂，要求按现有建模方法给出符合实际、随机组合的输入例子。
开始时 SAGE 上用户已提交并推送 `ef605ad evolution`（目录重组与 amorphous_bulk）；流水线、构建器避让和第三期仍未提交。

## 修改

- 简化输入：
  - 新增 `src/genkai/modeling/surface/builders/molecules.py`：常见气体名（ASE G2 几何：NO2、NO、CO、CO2、H2、O2、O3、
    H2O、NH3、H2S、SO2、CH4、CH3OH、C2H5OH、HCHO、CH3CHO、CH3COCH3、C6H6，及 ethanol、acetone 等别名）与
    `load_molecule`（文件或不带目录的气体名）。这张表原在 `executor.py`，现以 molecules.py 为唯一来源，执行器改为导入。
  - adsorbate 的 `--molecule` 可写气体名；`jobs.py` 新增参数类型 `molecule`：写气体名时保留名字，同名文件存在时按文件；
    `input_paths` 只检查真正的文件路径。
  - 流水线的 adsorbate 步骤默认 `coverage_counts: [1]`、`patterns: [uniform]`（写了就按写的；记录在 manifest，check 会显示）。
- 新增 `examples/recipes/`：12 个常见气敏体系配方（10 个只生成结构：SnO2+NO2、还原 SnO2+NO2、Pt/SnO2+CO、Pd/SnO2+H2、
  ZnO(10-10)+乙醇、SAM/SnO2+NO2、ALD TiO2 岛/SnO2+H2O、ALD TiO2 膜/SnO2+NH3、Pt/CeO2(111)+CO、非晶 SnO2+丙酮；
  2 个需要 MLIP：Pt/SnO2+CO 按能量挑选、晶体→熔融-淬火→非晶表面+丙酮），`inputs/`（SnO2、ZnO 纤锌矿
  a=3.2495 c=5.2069 u=0.3819、CeO2(111) slab、非晶 SnO2/TiO2、丁酸）和 README。`.gitignore` 加入 `examples/recipes/runs/`。
- 缺陷修复（由配方 07 发现）：ALD 岛属于“表面”（solid）部分，第二期的遮挡判断只看团簇/SAM/分子，
  岛下面的 Sn 仍被当作吸附位点，H2O 被放进岛里（最小接触比 0.4471，WARN）。修复：
  - `sites.exposed_indices`：同一部分的原子按 1.2 Å、不同部分的原子按 2.5 Å（`COVER_RADIUS_A`）判断是否被盖住；
  - `sites.surface_region`：各 solid 部分从各自的顶面算深度（岛之间露出的基底仍是表面）；
  - `adsorbate.unblocked_sites`：遮挡原子改为“与位点不同部分的原子”（含覆盖层）。
  未加标签或只有基底的结构结果不变。
- 测试：新增 `tests/modeling/test_recipes.py`（5 项：气体名与别名、任务文件里的气体名/同名文件、10 个结构配方 check、
  2 个 MLIP 配方在有配置时可解析、配方 01 端到端）；`test_pipeline.py` 新增岛遮挡回归测试（修复前失败）。
- 文档：使用手册开头“最快的上手方式”与 adsorbate 行、README、SKILL.md、AGENTS.md。

## 结构库 sample/ 与随机生成（`genkai-surface random`）

用户在 `sample/` 准备了结构库（30 个 MP 2026-09-28 凸包稳定晶体 + 2 个非稳定 AB2O3 参考相；30 个 PubChem 核对身份、
RDKit 生成构象的 VOC 分子；目录、来源与 SHA256 校验），要求用这些结构随机生成复杂表面或先得到非晶再做下一步，
并在 README 与 AGENTS 中写好用法，让其他 AI 能读懂项目原理。`sample/.venv` 由 `sample/.gitignore` 排除（库本体 3.8 MB）。

修改：

- 新增 `src/genkai/modeling/surface/app/random_jobs.py` 与命令 `genkai-surface random`（`--list`、`-n`、`--seed`、`-o`、
  `--scenarios`、`--crystals`、`--molecules`、`--mlip`）：读两个 catalog，按种子抽晶体、可用场景、分子与场景内选择，
  写出带中文说明头（体系、MP 编号、PubChem CID、极性面提示、是否需要 MLIP）的流水线文件和 `random_index.json`。
  场景：adsorption、defect（氧化物 O / 硫化物 S 空位）、metal（Pt/Pd/Au/Ag 13，半数先做空位、半数分子放在金属上）、
  sam（乙酸双齿；SiO2、NaNbO3 除外）、ald（a-TiO2/a-SnO2 岛）；`--mlip` 时加 amorphous（二元氧化物：熔融-淬火，
  密度取晶体的 93%）与 energy（逐步按 MLIP 能量挑选）。非凸包稳定参考相不参与抽样。
- 晶面规则 `PHASE_FACETS`：先用切面方法对 32 个晶体逐一试切（脚本在 scratchpad），全部用首选面得到化学计量 slab
  （96–504 原子，In2O3 用时 25 s）；LaCrO3、KNbO3、NaNbO3、7 个尖晶石 (001) 与 SrCu2O3 为极性终止面，生成文件中注明。
- 吸附 `--site-symbols auto`（`auto_site_symbols`）：表面欠配位的裸露阳离子；没有时取最外层（顶面 0.6 Å 内）原子，
  对 30 个晶体逐一核对（氧化物取阳离子，MoS2/WS2/SnS2 基面取 S，钙钛矿取 B 位）。首版误把 MoS2 的 Mo 当作裸露
  （S 不在 Mo 正上方），测试发现后改为上述规则。
- 空位 `--element`（默认 O，硫化物用 S）；`jobs.py` 参数表同步。
- 缺陷修复：吸附遮挡半径未计入摆放时的横向移动，In2O3 + Pd13 + 乙腈中 N 与 Pd 仅 1.11 Å（接触比 0.53，WARN）；
  半径改为“分子半径 + site_radius + 1.5 Å”，同一用例重跑 PASS。
- 测试 `tests/modeling/test_random_jobs.py`（6 项；无 sample/ 时跳过）：规则（参考相不抽、硫化物与 SiO2/NaNbO3 无 SAM、
  氧化物有 amorphous）、同种子可复现且全部通过 check、过滤与 MLIP 场景、auto 位点与 S 空位、--list 与错误、随机 defect 任务端到端。
- 文档：AGENTS.md 新增“项目工作原理（先读这一节）”（数据流、约定、常用命令、加新方法的步骤）并在目录结构加入
  `sample/`、`random_jobs.py`；README 更新开头介绍并新增“用结构库随机生成复杂表面（sample/）”（命令、方案表、
  生成文件示例、手写的“先非晶再建表面”示例）；使用手册、配方 README、SKILL.md。`.gitignore` 加入 `/random_jobs/`。

验证（本机 Windows + Python 3.11.9，结构生成，无能量）：

- 随机 6 个（seed 1）：全部 PASS，9.5 分钟；据此把吸附摆放次数设为 12、ALD 场景面内尺寸降为 12 Å，远处路径改用绝对路径。
- 覆盖测试：10 种类型不同的晶体 × 适用场景，47 条流水线，6 进程并行，8.4 分钟：45 PASS、1 WARN（In2O3 乙腈，已修）、
  1 FAIL（SiO2 SAM 无双齿位点，已排除）。
- 定向复测：21 个氧化物 SAM、6 个硫化物 auto 位点、In2O3 用例：并行时 4 个因本机内存不足失败（MemoryError），
  单独重跑全部 PASS；NaNbO3(001) SAM 无双齿位点，已排除。
- 最终：`python -m pytest -q` 245 passed / 2 deselected；`python scripts/run_modeling_smoke.py`（`.pytest_cache/random-smoke/`）
  PASS 31 / WARN 0 / FAIL 0 / SKIP 2，与上一轮 33 个用例逐项相同。`git diff --check` 通过。
