## 增强 PToModel 到表面建模脚本参数的对应关系

本次工作接续前几天的 surface experience / PToModel 清理，重点从“识别论文中的材料、晶面、吸附物、团簇语义”推进到“说明这些语义如何对应到可执行建模脚本参数”。当前仓库没有今日提交记录，主要依据未提交 diff 记录今天项目中的实际修改。

已完成：

- 更新 `paperread/surface/ptomodel.py`
  - 新增 `_infer_cluster_atom_count(...)`，支持从 `Pt13`、`13-atom cluster` 这类团簇描述中提取 `cluster_atoms`。
  - 新增吸附物候选规范化逻辑：
    - `_normalize_adsorbate_candidate(...)`
    - `_adsorbate_candidates(...)`
  - `adsorbate_landscape` 的 `task_inputs` 增加 `adsorbate_species`，用于把论文中的 adsorbate / reactant 名称进一步对应到后续 molecule structure file。
  - `surface_cluster_builder` 的 `task_inputs` 增加：
    - `cluster_atom_count`
    - `cluster_structures`
  - `task_argument_template.argument_sources` 增加参数来源元数据：
    - `confidence`
    - `source_field`
    - `source_term`
    - `depends_on`
  - 新增 `parameter_bindings` 输出，把参数值与来源说明放在同一层，便于 Agent 或人工直接查看每个参数当前状态。
  - 对结构文件类参数标记 `needs_upstream_artifact`，并显式写出依赖：
    - surface / input 依赖 slab generation 或用户选择结构文件。
    - molecule 依赖 molecule structure file。
    - cluster / cluster_bulk_file 依赖团簇结构生成或 bulk 文件选择。
  - 对 `vacancy_counts`、`coverage_counts`、`adsorption_sites`、`active_symbols` 等参数保留 `needs_manual_decision`，避免把论文语义强行转成不可靠数值。
  - 新增 `_build_parameter_correspondence(...)`，用于描述跨任务共享的表面结构、吸附物到分子文件、覆盖度到 coverage counts、团簇短语到 builder 参数等对应关系。

- 更新 `ptomodel_mapping.md`
  - 新增“参数种类左右对照”章节。
  - 按三个已启用建模脚本整理建模侧参数与论文抽取侧字段的对应：
    - `vacancy_landscape`
    - `adsorbate_landscape`
    - `surface_cluster_builder`
  - 明确哪些参数可以从论文中直接或半自动获得，哪些属于上游结构文件、人工决策或执行配置。
  - 将 `clusters` 到 `surface_cluster_builder.cluster_atoms` 的映射写入字段对应关系。
  - 更新自动填充规则，记录 `Pt13` 等显式团簇尺寸可自动映射到 `cluster_atoms`。
