## 新增 paperread 本地经验收集

参考 Agent 计算模拟经验收集方式，在 `paperread/surface` 中新增本地经验收集入口：

```text
paperread/surface/collect_experience.py
paperread/surface/experience/.gitkeep
```

用途：

- 从 `*_surface_relations.jsonl` 和 `*_table.csv` 中收集已知有用信息和未知信息。
- 参考 NERRE/ReactionSeek 的 schema-driven 方式，只从表面建模目标字段收集经验，不再全量收集文本中的性能、反应参数和应用描述。
- 按表面材料研究类别聚合去重：
  - `surface_materials`
  - `surface_structure`
  - `defects_active_sites`
  - `adsorption_reaction`
  - `clusters_single_atoms`
  - `modeling_tasks`
  - `unknown_information`
- 额外生成 `material_classes` 主索引，使经验能按无机材料种类查看，而不是按论文查看。

当前无机材料种类列表：

- `single_atom_catalysts`
- `supported_catalysts`
- `metals_alloys`
- `oxides`
- `hydroxides_oxyhydroxides`
- `sulfides`
- `selenides_tellurides`
- `nitrides`
- `carbides_mxenes`
- `phosphides_phosphates`
- `halides`
- `carbon_materials`
- `perovskites_spinels`
- `zeolites_silicates`
- `mofs_coordination_polymers`
- `borides`
- `defect_engineered_materials`
- `surface_functionalized_materials`
- `battery_electrode_materials`
- `other_inorganic_materials`
- 为后续更新 prompt、schema、`modeling_planner.py` 和 Agent skill 提供依据。

新增 pipeline 参数：

```bash
python -m paperread.surface.run_surface_pipeline paper.pdf \
  --output-dir paperread/surface/output \
  --collect-experience
```

独立使用方式：

```bash
python -m paperread.surface.collect_experience \
  --relations paper_surface_relations.jsonl \
  --table paper_table.csv
```

默认输出：

```text
paperread/surface/experience/material_classes/<material_class>.json
```

说明：

- 材料种类 JSON 是长期经验库的默认输出。
- per-run `.json` 和 `.md` 只是人工审阅报告，后续仅在显式传入 `--write-run-file` / `--write-markdown` 时生成。

## 两个测试 PDF 的 paperread 实测

测试文件：

```text
tests/test.pdf
tests/test2.pdf
```

测试输出目录：

```text
tests/paperread_pdf_test/
```

直接对 `tests/test.pdf` 运行完整 PDF pipeline 时，PDF ingestion 成功，但 LLM 请求触发上下文限制：

```text
Error code: 413
Request body too large for gpt-4o-mini model. Max size: 8000 tokens.
```

因此本轮采用短输入测试策略：

- 先从两个 PDF 提取文本和章节。
- 为每个 PDF 生成短版 conditions/relations JSON。
- 用短版输入运行完整 JSON pipeline。
- 启用 `collect_experience_output=True`。

生成的短输入：

```text
tests/paperread_pdf_test/test_short_conditions_input.json
tests/paperread_pdf_test/test_short_relations_input.json
tests/paperread_pdf_test/test2_short_conditions_input.json
tests/paperread_pdf_test/test2_short_relations_input.json
```

`tests/test.pdf` 输出：

```text
tests/paperread_pdf_test/test_short_conditions_input_table.csv
tests/paperread_pdf_test/test_short_conditions_input_time.csv
tests/paperread_pdf_test/test_short_conditions_input_surface_relations.jsonl
tests/paperread_pdf_test/test_short_conditions_input_summary.txt
```

`tests/test2.pdf` 输出：

```text
tests/paperread_pdf_test/test2_short_conditions_input_table.csv
tests/paperread_pdf_test/test2_short_conditions_input_time.csv
tests/paperread_pdf_test/test2_short_conditions_input_surface_relations.jsonl
tests/paperread_pdf_test/test2_short_conditions_input_summary.txt
```

抽取结果概况：

- `test.pdf`
  - 识别到 Tin、Graphene、Sn SAs/G、single atom、sodium、sp hybridization、sodium metal batteries 等信息。
  - 经验收集能区分 `known_useful` 和 `unknown_high_value`。
- `test2.pdf`
  - 识别到 nickel、graphene-like carbon、Ni-O-G SACs、graphene surface、O-terminated、nickel single atoms、oxygen evolution reaction 等信息。
  - 经验收集能保留单原子催化剂、表面终止和性能指标相关信息。

测试后的改进：

- 将以下术语加入 `paperread/surface/collect_experience.py` 的已知词表，减少误判为 unknown：
  - `terminated`
  - `O-terminated`
  - `metal-terminated`
  - `single atoms`
  - `single metal atoms`
  - `SAC`
  - `SACs`

结论：

- 两个 PDF 的短输入 pipeline 均已跑通。
- 新增 experience 机制能将经验写入材料种类经验库。
- 完整 PDF 直接送入模型仍需要后续增加自动分块/压缩机制，避免 8000 token 限制。
