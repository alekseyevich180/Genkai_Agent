### 空位：`vacancy.py`

- 只有 CLI `main()`，没有程序化 API；`oxygen_indices()` 只挖 O，按晶胞分数坐标
  `--z-frac-min/--z-frac-max` 选候选。
- `sample_vacancy_sets()`：组合数不超过 `--samples-per-count` 时全枚举，否则随机抽样；
  没有对称去重。
- `E_vac = E_defect − E_clean + n·μ_O`；`--calculator uma|none`。`none` 的模拟计算器只给
  Ce、O 赋能量（−4、−2 eV），只适用于 CeO2 流程测试。
- 先对干净 slab 做 LBFGS（默认 `max_steps=200`），再对每个缺陷结构优化。
- 输出：`structures/ov_*.cif`、`clean_relaxed.cif`、`stable_vacancy_structure.cif`、
  `vacancy_energy_landscape.csv/.png`、`run_config.json`。CIF 丢失 `FixAtoms` 和 tags，
  不产出 extxyz，不登记 artifact。
- 参数 schema：`src/genkai/modeling/schema/task_parameter_schema.json:38`；PToModel 根据
  `defects`/`vacancy_models` 中含 “vacan” 的线索添加任务（`mapping.py:549-556`）。

### 预吸附氧与湿度物种

### 贵金属团簇：`metal_cluster/`

- `cluster_builder.py`：从体相超胞按原子数、壳层数或半径截取团簇；内置 19 种金属
  （Ag Al Au Cd Co Cr Cu Fe Mg Mo Nb Ni Pb Pd Pt Ti V W Zn）的 fcc/hcp/bcc 最近邻
  距离；Rh、Ru、Ir、Os 不在内置表中，需要 `--cluster_a`、体相文件或 Materials Project。
- `fcc.py`：fcc{111} 按行堆叠，形状 triangle/hexagon/trapezoid/rectangle/custom，
  ABC/AB 堆叠；`hcp.py`：hcp{0001}；`bcc.py`：bcc{110} 桥位行。
- `surface_cluster_builder.py`：`place_cluster_on_surface()`（第 31 行）按分数坐标
  `--x_frac/--y_frac`、底部间隙 `--z_height`、欧拉角放置；slab 来自 `--surface` 或
  Materials Project（`--surface_formula`/`--surface_mp_id`，需联网）。输出
  `*_cluster.cif`、`*_on_surface.cif`、`modeling_manifest.json`；CIF 丢失固定原子；
  只支持单元素团簇。
- `cluster_search.py`：Optuna 搜索团簇在 slab 上的位置和取向，每次试验用 UMA 弛豫，
  默认 `--device cuda`，并为 DFT 挑选候选；不属于 structure-only。

### 开发中发现并修复的问题

1. 小晶胞配位数偏低：用最小镜像距离矩阵时每对原子只计一次，金红石原胞（c = 3.19 Å）中
   Sn 被算成 4 配位。改用 `ase.neighborlist.neighbor_list`（逐镜像计数），新增回归测试。
2. 长分子跨 c 折回：最小镜像接触检查会把超出晶胞高度的分子折回 slab 底部。放置前先加高 c。
3. 链间排斥过宽：分子之间改用 0.8 × 范德华半径和（分子与 slab 仍用共价半径 + 0.4 Å）。
   C10 硫醇在 Au(111) 3×3 上 3 个分子（4.62 nm⁻²）时，链间最近 H…H 从 1.90 Å 升至
   2.08 Å，C…C 为 3.60 Å。manifest 新增 `min_intermolecular_distance_A`。
4. `min_contact_ratio` 被设计成键（锚定键、O–H）主导，恒约 1.0。新增
   `min_nonbonded_contact_ratio`，排除设计成键。

### 实测（structure-only，calculator=none）

- SnO2 体相不给晶面时，按注册表取 (110)，3×2 超胞 144 原子，含 6 个 Sn5c 和 6 个桥氧。
- 甲基膦酸：双齿时 2 个 Sn–O 均为 2.05 Å，2 个 H 转移为桥氧 OH（0.98 Å），组成守恒；
  请求 3 个只放下 2 个（每条 Sn5c 链只能容纳 1 个双齿分子），记为失败的覆盖度；三齿时
  无 3 个相距 ≤ 4.55 Å 的 Sn5c，被阻断。
- CH3SH 在 Au(111) 的 fcc/hcp/bridge/top 位：Au–S 2.41 Å，倾角 30°，H 去除。
  C10 膦酸在 SnO2(110) 上双齿 1、2 个；C10 硫醇在 Au(111) 上 fcc 位 1/2/3 个，均成功。
- 分子 CIF 被故意折成跨晶胞面的两半，读入后键长全部恢复。
- ALD 全覆盖，6 Å，2 个样本：
  - a-SnO2 / SnO2(110)：slab 1×3、非晶 1×4，主应变 −1.1% / +4.0%，432 + 172~176 原子，
    O/M 1.93~2.07（体相 2.0），膜密度 6.13~6.47 g/cm³（体相 6.61），界面接触比 ≥ 1.17。
  - a-TiO2 / TiO2(110)：主应变 −0.1% / +2.3%。
  - 膜内最小接触比与体相相同（SnO2 0.97 对 0.964；TiO2 0.799 来自原始结构中 1.80 Å 的
    Ti–O），说明没有周期接缝。
- ALD 部分覆盖，30 原子岛：slab 扩为 3×2（864 原子），岛直径约 12 Å，与周期镜像间隔
  14.8~18.7 Å，占面积约 8~10%。
- extxyz 读回：FixAtoms、tags（0/1/2）、`fragment_id`、`sam_role`/`ald_role` 均保留。

## 哪些建模步骤会用到 DFT 或 MLIP（只读查询）

| 脚本 | 步骤 | 能量模型 | 用途 |
|---|---|---|---|
| `slab.py` | 未给晶面时：各晶面和终止面的表面能 → Wulff 面积占比 → 最稳定面 | `--calculator emt/uma`；默认 `none` 时查注册表；`--relax-steps` 默认 0，即静态单点 | 筛选晶面和终止面 |
| `vacancy.py` | 先弛豫干净 slab，再逐个弛豫空位构型，按 E_vac 排序，输出最稳定结构 | UMA（task 默认 omat，可加 D3），LBFGS 最多 200 步 | 筛选空位构型 |
| `adsorbate.py` | Optuna 搜索单分子位置（每次试验都弛豫）→ 生成覆盖度结构并弛豫 → 按 E_ads/N 排序 | UMA | 筛选吸附构型和覆盖度 |
| `cluster_search.py` | 先弛豫 slab 和团簇；Optuna 搜索放置并逐个弛豫（fmax 1e-4）；剔除脱附的；排序；取前段加尾部分箱样本，作为 DFT 候选，输出 POSCAR | 只能用 UMA（task 默认 oc22） | MLIP 预筛 → 交给 DFT |
| `executor.py` | 只生成结构（calculator none、max_steps 0）；放置用模拟计算器 | 无 | — |
| `sam.py` / `amorphous_overlayer.py` / `amorphous_slab.py` / 团簇构建 | 几何放置；SAM/ALD 只在从体相切面且不给晶面时，经 substrate 使用表面能排序 | 无（或经 slab.py） | — |
| DFT | `paper_to_mlip`：surface → vasp-prepare（只写计划，不提交）→ vasp-collect（解析收敛的 OUTCAR，需 dpdata）→ dataset → deepmd/uma | VASP（skill 侧准备输入、外部运行） | 标签和验证 |
| MACE | `paper_to_mlip --target mace`：对结构集做预训练 MACE 推理或弛豫（适配层只准备和预检） | MACE | 可替代 UMA 做预筛 |

服务器运行前需要注意：

- vacancy、adsorbate、cluster_search 直接 `read()` slab，不施加 FixAtoms。输入为 CIF（如 skill 示例）时，
  弛豫会让整个 slab 都移动；应改用带固定信息的 extxyz/POSCAR，或在脚本中补上固定。
- slab.py 的表面能默认是未弛豫的静态值。
- cluster_search 写 POSCAR 时 `sort=True`，原子顺序与其 CIF 输出不同。
- cluster_search 默认 `task_name=oc22`，需要先确认服务器上 fairchem 版本是否支持。
- `calculator=none` 时的能量来自模拟计算器，没有物理意义；吸附脚本此时把最佳结构命名为
  `workflow_test_best_candidate.cif`，以示区别。

### SAM 与非晶部分：现状与 MLIP/DFT 接入点（只读）

`sam.py`、`amorphous_slab.py`、`amorphous_overlayer.py` 都不调用能量模型（manifest 中为
`calculator: none`）。`sam.py` 中的 `scipy.optimize.minimize` 优化的是几何目标（键长、倾角、
避免过近），不是能量。唯一的能量入口是 substrate → slab.py 的表面能选面（`--calculator`）。

建议在服务器阶段接入 MLIP 的位置：

- SAM：
  - 各结合方式弛豫后比较能量。氧化物上 H 转移后组成相同，可以直接比较总能量。
  - 对多个位点和起始取向分别弛豫，取最低能量。
  - 比较 H 接受位点的不同选择。
  - 计算 E_ads/N 随覆盖度的变化。
  - 长链 SAM 用 MD 退火确定堆积和倾角。
- 非晶：
  - 体相可用 MLIP melt-quench 生成，仓库目前没有这个流程。
  - 纯非晶 slab 的各个样本先弛豫（可加短时退火），再比较表面能。
    厚度取整数个周期时组成符合化学计量，表面能可以直接比较。
  - ALD 膜做界面弛豫，并比较粘附能；切割方式的接缝尤其需要弛豫。
  - ALD 岛用 Optuna + UMA 搜索放置。可以复用 `cluster_search.py`，但 ALD 目前不单独输出岛的文件。
- DFT：
  - 对 MLIP 筛出的少数候选做单点或弛豫验证；
  - 电子性质（功函数、电荷转移、能带对齐、缺陷态）只能用 DFT。

### 用户方案中可以使用 MLIP 的位置（设计分析，未写代码）

用户方案：
- SAM：选定结合方式 → 用 Optuna 搜索稳定结构 → 按覆盖度复制、移动分子 → MLIP。
- 非晶分三种情况：(1) 纯非晶：切出多种表面，比较表面能；(2) 全覆盖：在 (1) 基础上做晶胞匹配，
  旋转、平移下层晶体，求整体能量最低；(3) 岛：先简单优化一次，再用 Optuna 相对表面旋转、平移岛。

本机核对：
- fairchem 2.7.1 的 UMATask 为 omol / omat / odac / oc20 / oc25 / omc，没有 oc22，
  因此 `cluster_search.py` 默认的 `--task_name oc22` 在此版本不可用。
- 现有 Optuna 参数：`adsorbate.py` 为 group_id、spin_angle（绕 z）、dx、dy、z_gap；
  `cluster_search.py` 为 spin_angle（绕底面法向）、x_frac/y_frac 或 site_index+dx/dy、z_gap。

结论：
- 共同前提：
  - 同一组比较使用同一模型、同一任务头、同一组设置，参考能量也一样；
  - 只有组成相同的结构才能直接比较总能，否则比较吸附能、粘附能或表面能；
  - 底层固定方式要一致；
  - 非晶以及有机分子与氧化物的界面属于外推，需要 DFT 抽查；
  - 电子性质不用 MLIP。
- SAM：
  - Optuna 要在“锚定参数”上搜索（位点组、倾角、方位角、绕分子轴自旋、H 接受位）；
    不能直接套用 adsorbate.py 的自由放置，否则会丢掉选定的结合方式。
  - 每次试验先几何放置，再 MLIP 短弛豫，并检查锚定键是否仍在。
  - 复制分子来构造覆盖度，只适用于平移等价的晶面位点；复制后要整体再弛豫。
  - 非晶表面上的位点互不等价，每个分子都要单独搜索。
  - 带电头基（咪唑盐）必须带上反离子，保持体系电中性。
- 非晶 (1)：
  - 先用同一 MLIP 弛豫非晶体相（包括晶胞），得到每原子能量 ε_bulk；
  - 厚度取整数个周期，保证化学计量；
  - 底面固定会混入未弛豫的表面能，要用一致的公式扣除，或者两面都放开弛豫。
- 非晶 (2)：
  - 在周期性约束下，旋转只能取离散值（不同的 ZSL 匹配，或切割时的旋转）；
  - 不同候选的原子数不同，比较粘附能 W_adh/A；
  - 平移和间隙可以用 Optuna 加 MLIP，组成相同，可直接比较总能；
  - 非晶膜还需要 MLIP MD 退火。
- 非晶 (3)：
  - 可复用 cluster_search 的 Optuna 加 MLIP，但需要增加倾斜角，补上单独的岛文件输出，
    并换成可用的任务头；
  - 孤立岛在真空中充分弛豫可能明显变形：参照能量用充分弛豫的岛，放置用切出时的形状；
  - 体系约 900~1500 原子，宜分两段筛选。

### 开发中发现并修复的问题

1. ASE 的 json 格式不保留自定义逐原子数组。Optuna 试验中保存的结构改用 extxyz 字符串。
2. 模拟计算器没有应力。弛豫晶胞时，若是模拟计算器则跳过晶胞过滤器。
3. 非晶切面会因删除孤立原子而偏离化学计量（a-SnO2 4 个样本中 3 个）。改为扫描切割位置，
   只取不删原子的窗口后，4/4 都符合化学计量（O64Sn32、O64Ti32）。
4. `Ru_hcp_r7.xyz` 是半径 7 Å 的 Ru 颗粒（约 150 个原子），不是 7 个原子的团簇。放上去后与 slab
   周期镜像只隔 3.98 Å（冒烟 WARN）。`cluster_search` 新增 `--min_vacuum`，在弛豫 slab 前加高 c；
   新增回归测试；冒烟用例描述已更正。
5. 测试假设 a-SnO2 在 SnO2(110) 上有多个晶格匹配，实际 5%/600 Å² 内只有 1 个。改用 a-TiO2。
