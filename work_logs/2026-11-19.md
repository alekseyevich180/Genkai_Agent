# 2026-11-19：论文建模自动化接通（七类结构生成方法 + 串联）

## 背景与范围

用户要求先处理论文建模部分：此前论文流程（`init` / `surface run --modeling-mode structure-only`）
只执行切面和吸附，空位、团簇、SAM 被标为未注册，ALD 和非晶表面不会被识别成任务。

确认的选择：

- 空位、团簇、SAM、ALD、纯非晶表面五类都接入，并支持任务串联；
- ALD/非晶识别：修改 LLM 抽取提示词，同时在建模计划中用关键词识别（已保存的抽取结果也能用）；
- 论文给不出的输入：默认仍停下列出缺项；新增显式开关 `--accept-defaults`，只对数值参数取默认值并记录，
  结构文件和 SAM 结合方式仍必须提供。

开始时 `git status --short --branch` 为 `main...origin/main`，工作区干净（HEAD `c0c5685`）。
只在 main 上修改；没有改动 SAGE 分支，没有提交或推送。

## 实际修改

- `literature/surface/core/surface_ontology.py`：新增任务 `sam_functionalization`、`ald_overlayer`、
  `amorphous_slab`（均可执行）；`surface_functionalization` 保留为普通端面状态（暂缓）。
- `literature/surface/extraction/extract_surface_relations.py`：抽取 schema 新增 `sam_molecules`、
  `overlayers` 字段及说明；推荐任务名加入三个新任务并说明区分方式。
- `modeling/mapping.py`：
  - 新增 `_surface_modification_cues`：只看端面、修饰、表面、材料、材料参数、覆盖度、关键词等字段
    （不看吸附物/产物，避免把羧酸产物当成 SAM）。SAM 证据：SAM、self-assembled、膦酸/羧酸/硫醇/硅烷；
    锚定基团与结合方式（单齿/双齿/三齿）有唯一提法时取用。ALD 证据：ALD、atomic layer deposition；
    或 overlayer/coating/shell/conformal 且含氧化物化学式、不含 drop/spin/dip-coat、electrode、substrate。
    覆盖方式（岛/部分 vs 连续/保形/膜）、膜厚（nm/Å）、ALD 循环数、覆盖层化学式。非晶证据：amorphous、a-SnO2。
  - `_infer_tasks`：新任务不受材料类别限制；推荐的 `surface_functionalization` 在有 SAM 证据时改为
    `sam_functionalization`；端面描述按是否 SAM 拆分；有 ALD 证据时不再额外加 `amorphous_slab`。
    任务选择记录中保存全部识别证据（`surface_modification_cues`）。
  - `_build_task_inputs` 与参数模板：三个新任务的输入与绑定。ALD 膜厚 ≤ 20 Å 按论文值，更厚或只有循环数时
    待人工决定；非晶 slab 厚度一律待人工决定（论文给出的是真实膜厚，不是模型厚度，只写入理由）。
    `_build_task_inputs` 的 payload 加了类型注解。
- `modeling/schema/task_parameter_schema.json`：末尾追加三个任务的参数定义。
- `modeling/surface/executor.py`：
  - 新增覆盖参数：`chain`、`accept_defaults`、空位（counts/samples）、团簇（element/atoms/structures）、
    SAM（molecule/binding_mode/counts/anchor_kind）、ALD 与非晶（amorphous/coverage/thickness/island_atoms/
    amorphous_thickness）。
  - 解析：覆盖 → 计划 → 默认值（需开关）→ 缺项；缺项提示写明对应参数与 `--accept-defaults`。
    团簇晶格类型取元素基态（ASE 参考数据）。有 `amorphous_slab` 且无 ALD 时以非晶 slab 为基底，跳过晶体切面。
  - 执行：统一的运行函数接口；空位（顶部 2.5 Å 内的自由 O，按种子采样）、团簇（`build_nanocluster`
    放在胞中心、2.5 Å 间隙）、SAM（`run_sam`）、ALD（`run_overlayer`）、非晶 slab（`run_amorphous_slab`）、
    吸附（原逻辑）。均直接调用库函数，不经 Skill 脚本。

## 开发中发现的问题

1. 团簇构建器的晶格常数缺陷（见上）。原有冒烟 `cluster_pt13_on_ceo2` 的最小接触比 0.7248 正是被压缩的 Pt–Pt，
   因高于 0.6 阈值一直标为 PASS。
2. 串联后在团簇上吸附 CO 时顶部真空只剩 7.3 Å，已加入吸附结构的真空加高。
3. 首版把修饰物列表全部当作 SAM 分子（含 “O2 plasma activation”），改为只取出现在 SAM 描述里的名称。
4. 首版注册表保存函数引用，导致测试中的 monkeypatch 失效，改为调用时按名称查找。
5. 用 Python 脚本修补文件时注意保持换行风格；本次含转义的修改用 Edit 工具。
