## 项目审阅结论

- 论文到计划这一段已较完整，但自动化停在“计划”：
  `genkai.modeling.surface.build_surface_candidates` 只写命令计划，
  `structure_count=0`；`slab_generation` 被标为 deferred，而它是所有表面任务
  的上游。
- PToModel 输出中大量参数为 `null` + `needs_manual_decision`，缺少带理由的默认
  策略层，自动流程会频繁停下。
- 建模脚本的科学问题：没有固定底层原子、空位采样未按对称性去重、分子只绕 z
  轴旋转、弛豫后没有脱附/解离/重构检查。

## 正确性修复（已由用户提交：`56e0b91`、`34c21cf`、`7cb4108`）

1. PToModel 把任务键（如 `vacancy_landscape`）自动填入 UMA 的 `task_name`，
   `FAIRChemCalculator` 会直接 assert 失败。现改为不填，并在 schema 中注明
   `task_name` 是 UMA task head。
2. 晶面回退表 `Fm-3m -> (111)` 对岩盐氧化物错误。现按化学计量区分：单质
   (111)、AB 岩盐 (100)、AB2 萤石 (111)，其他 Fm-3m 组成停止并要求审查。
3. `ads_nanocluster.py` 写死 `oc22`。新增 `--task_name`（默认仍为 `oc22`）；
   三个表面脚本都写 `run_config.json`，记录模型、task head 和设备。
4. Windows 下 artifact 路径校验拒绝 `WindowsPath`。改为先转 POSIX；纯字符串中
   的反斜杠仍拒绝。原始提交在 Windows 上 contracts/workflow/integrations 有 12 个
   失败，修复后剩 4 个（均为 Windows 环境问题，见“验证边界”）。
5. 吸附位点分组、组质心和 uniform/clustered 覆盖模式没有最小镜像。4x4 Pt(111)
   上 4 个吸附物的“uniform”模式原本最小间距 1.00 nn，修复后为 2.00 nn。
6. `LaOx clusters` 被映射成金属 La 团簇。化合物式（LaOx、CeO2、PtNi）不再作为
   `cluster_element`；Ru/LaOx–SiO2 论文重放后回退到活性位点得到 Ru（medium）。

## 基于 pymatgen 的自动切表面（未提交，分支 `main`）

新增稳定库模块 `src/genkai/modeling/slab.py`，skill 脚本只做薄入口：

- 体相先转惯用标准胞再套 Miller 指数。审阅中新发现：MP 常返回原胞，旧代码直接
  在原胞基矢上切面，MgO 原胞的 `(1,0,0)` 实际切出 `{111}`；除 (111) 外的晶面
  指数基本都会切错。
- 晶面决策顺序：显式晶面 -> 注入能量函数时按表面能 + Wulff 面积占比排序 ->
  审查过的注册表 -> 停止并要求人工审查。
- 用 `SlabGenerator` 枚举全部终止面，按非极性、化学计量、表面能、对称性排序。
  极性判断前先标注猜测的氧化态（否则 `is_polar()` 恒为 False）；无法猜测时
  标为 `polarity_unknown` 而不是默认非极性。
- 输出几何：c 轴正交于表面，按垂直宽度扩胞到 `min_lateral_size`（默认 8 Å），
  底部一半（或指定层数）`FixAtoms`，tags 为 0 = 固定次表层、1 = 表面区
  （Open Catalyst 约定）。
- 校验：真空层、原子重叠、面内尺寸、顶层未固定、极性、化学计量；把 slab 当
  体相输入会被拒绝。
- 表面能 `γ = (E_slab − N·ε_bulk)/(2A)` 只对化学计量终止面定义；能量函数为
  `Callable[[Atoms], float]`，库本身不依赖特定 MLIP。

接入：

- 新 CLI `agents/Agent/skills/surface-modeling/scripts/surface/slab_generation.py`：
  `--bulk` / `--formula` / `--material-id`，`--calculator none|emt|uma`，输出
  `slab.vasp`（selective dynamics）、`slab.extxyz`、`bulk_conventional.cif`、
  `slab_manifest.json`、`run_config.json`。
- `materials_project_slab.py` 改为调用该库，旧函数名和 manifest 键保持兼容，
  团簇脚本的 MP 路径因此也使用惯用胞和固定底层。
- `slab_generation` 加入参数 schema 和 `EXECUTABLE_TASKS`。PToModel 自动映射：
  论文晶面 -> `facet`；明确氧化物式或单质 -> `formula`；否则请求体相文件。
- `pyproject.toml` 将 `pymatgen>=2025.6.14` 声明为直接依赖。
- 更新 surface-modeling 与 ptomodel 的 `SKILL.md`。

### 代表体系结果

| 体系 | 晶面来源 | 结果 |
|---|---|---|
| MgO 原胞 | 注册表 | (100)，每层同时含 Mg/O，非极性 |
| MgO 指定 (111) | 显式 | 极性终止面，给出 `polar_termination` 警告 |
| CeO2（原胞或惯用胞） | 注册表 | (111)，O–Ce–O 化学计量对称终止面，108 原子 |
| 金红石 TiO2 | 注册表 | (110)，化学计量对称终止面 |
| Cu / Pt（EMT 表面能） | 计算 | γ(111) < γ(100) < γ(110)，Wulff 选 (111) |
| hcp Ru | 注册表 | (001) |

论文重放：Ni/CeO2 论文现在生成可执行 `slab_generation`（`formula=CeO2`，晶面留给
注册表或表面能排序）；生成的 CeO2(111) slab 可直接交给
`surface_cluster_builder.py` 放置 Pt13（121 原子）。
