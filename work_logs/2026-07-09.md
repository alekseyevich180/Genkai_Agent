# 2026-07-09 工作日志

## 解决 unknown data 中的晶面指数换算问题

本次接续 2026-07-08 unknown-term 清洗结果，优先处理 `facet_or_miller_index` 类 unknown。核心问题是晶面指数不能只做字符串归一化，必须结合材料的晶体结构、space group 和软件切表面的三指数输入约定。

已完成：

- 新增 `paperread/surface/surface_indices.py`
  - 解析普通 Miller 三指数与 hexagonal Miller-Bravais 四指数。
  - 支持 Unicode overbar，例如 `(101̅4)`、`(0112̅)`。
  - 将 hexagonal/hcp 四指数 `hkil` 转成软件常用三指数 `(hkl)`。
  - 内置首批结构上下文：
    - `Ru`: hcp, `P6_3/mmc (No. 194)`, `Ru(0001)` -> `(001)`。
    - `ZnO`: wurtzite, `P6_3mc (No. 186)`, `ZnO(10-10)` -> `(100)`。
    - `β-CoOOH`: layered hexagonal/trigonal context, `β-CoOOH(0112̅)` 按常见抽取错位修正为 `(01-12)`，软件输入 `(012)`，并保留 warning。
- 更新 `paperread/surface/ptomodel.py`
  - `normalized_mapping.facet_set` 现在输出软件可用三指数。
  - `selected_information.surface_facets[]` 增加 `surface_index` 结构化字段，保留原始指数、输入 notation、软件 Miller index、space group/structure 提示和 warnings。
- 更新 `paperread/surface/collect_experience.py`
  - `exposed_surfaces` 能识别带 overbar 的四指数。
  - class profile 增加 `surface_index_mappings`。
  - 对孤立的 `(0112̅)` 这类 facet，会从同一 profile 的材料词中带入 `β-CoOOH`、`ZnO`、`Ru` 上下文后再换算。
- 更新 `paperread/surface/parameter_registry.py`
  - registry JSON/Markdown 增加 surface index mappings。
  - prompt hint 会回灌 `facet mappings`，便于后续抽取和 PToModel 使用。
- 更新 `paperread/surface/unknown_terms.py`
  - `classify_unknown_term` 改用结构化 surface index parser。
  - `(101̅4)` 等四指数不再落入 `other_unknown`。
  - 修复 material-class store 刷新条件，使 profile 字段变化也能写回。

## 增加矿物/晶体结构原型词典

根据进一步检查，`rutile`、`spinel`、`anatase`、`perovskite` 等词不应作为普通 material unknown 处理。这类矿物名/结构原型名往往直接提示晶体结构、space group family 和可用的 facet notation。

追加修改：

- 新增 `paperread/surface/crystal_structures.py`
  - 集中维护晶体结构/矿物原型词典。
  - 首批包含：`rutile`、`anatase`、`brookite`、`spinel`、`normal spinel`、`inverse spinel`、`perovskite`、`fluorite`、`wurtzite`、`rocksalt`、`rock salt`、`pyrochlore`、`delafossite`、`brucite`、`corundum`。
  - 每个词条记录 family、crystal system、typical space group 和必要说明。
- 更新 `paperread/surface/surface_ontology.py`
  - `is_known_surface_experience_term` 能识别结构原型词。
- 更新 `paperread/surface/collect_experience.py`
  - class profile 新增 `crystal_structure_terms`。
  - `_detect_spacegroup_terms` 改为复用结构词典，不再靠零散字符串。
- 更新 `paperread/surface/parameter_registry.py`
  - registry common 增加 `crystal_structure_keywords`。
  - Markdown/prompt hint 增加 crystal/mineral structure keywords。
- 更新 `paperread/surface/unknown_terms.py`
  - reclassify 时将结构原型词提升为 `known_useful`，category 为 `surface_structure`。
- 更新 `agents/Agent/skills/paperread/SKILL.md`
