### 虚拟环境启动

- 默认使用
  `/home/pj24001724/ku40000345/wu/UMA-campare/.venv_uma`。
- 批处理脚本通过设置 `VIRTUAL_ENV`、更新 `PATH` 并直接调用
  `.venv_uma/bin/python` 完成环境启动，不依赖交互式 shell 的 `source` 状态。
- 支持通过 `UMA_RUNTIME_DIR`、`UMA_VENV_DIR` 和 `UMA_PYTHON_BIN` 覆盖运行环境。
- FAIR-Chem 与 matplotlib 沿用 UMA 运行目录中的共享缓存；模型下载默认关闭。

### 计算接入与输出位置

- 使用 `UMA_WORK_DIR` 指定每个计算的工作目录，并通过
  `UMA_PYTHON_SCRIPT`、`UMA_PYTHON_ARGS`、`UMA_DEVICE` 和 `UMA_THREADS`
  接入具体 Python 计算入口和运行参数。
- 每次计算使用独立目录：
  `mlip/<时间戳>.uma_<任务名>/`。
- 该目录同时作为输入与输出目录，统一保存 Python 入口、结构与配置输入、弛豫结构、
  能量/力结果、轨迹、优化器或 MD 日志以及中间产物。
- PJM 提交使用 `-o <run_dir>/uma_calc.out`，将合并后的标准输出和错误输出固定保存
  在同一任务目录。
- 增加本地 `UMA_DRY_RUN=1` 预检流程；预检只检查环境、入口和完整命令，
  不启动计算、不提交作业。
