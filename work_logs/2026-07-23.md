### MACE 虚拟环境启动

- 默认运行目录为 `/home/pj24001724/ku40000345/wu/MACE`，默认虚拟环境为
  `/home/pj24001724/ku40000345/wu/MACE/.venv`。
- launcher 自动设置 `VIRTUAL_ENV`、更新 `PATH`，并直接调用
  `.venv/bin/python`，无需预先执行交互式 `source`。
- 默认 Python 入口为
  `/home/pj24001724/ku40000345/wu/MACE/scripts/run_mace_calculation.py`；
  可通过 `MACE_RUNTIME_DIR`、`MACE_VENV_DIR`、`MACE_PYTHON_BIN` 和

### 调用与提交

- 每个任务使用独立目录 `mlip/<时间戳>.mace_<任务名>/`，通过
  `MACE_WORK_DIR` 同时指定输入与输出目录。
- 使用 `MACE_MODEL`、`MACE_DEVICE`、`MACE_THREADS` 和
  `MACE_PYTHON_ARGS` 传入模型、设备、线程数和简单命令行参数。
- `MACE_DRY_RUN=1` 只检查环境、入口和最终命令，不启动计算；Agent 的
  `run_skill_script` 只用于这种非计算预检，不用于长时间 CPU/GPU 任务。
- 正式 GPU 任务由 `pjsub` 调用 launcher，并通过逗号分隔的
  `-x "MACE_WORK_DIR=...,MACE_DEVICE=...,..."` 传递环境变量。
- PJM 合并日志写入任务目录中的 `mace_calc.out`。单点计算输出
  `results.json` 和 `evaluated.extxyz`；弛豫任务还输出
  `relaxed.extxyz`、`optimization.traj` 和 `optimization.log`。
